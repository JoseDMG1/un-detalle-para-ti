# 🌻 Para María Isabel

Un regalo digital hecho con HTML, CSS y Canvas puro: flores amarillas interactivas que brotan al tocar, lluvia de pétalos dorados, música de campanas suave y un mensaje sorpresa oculto al final.

## ✨ Lo que incluye

- Fondo de atardecer nocturno con resplandores dorados y pétalos cayendo todo el tiempo.
- **Toca cualquier parte** → brota una flor amarilla, explota en pétalos y sparkles dorados, y suena una campanita (volumen bajo, con audífonos se disfruta más).
- Contador de flores enviadas y corazones "Te amo" flotando.
- Botón **"Soltar las flores"** → avalancha de flores y pétalos por toda la pantalla.
- **Mensaje sorpresa** que se revela al enviar 10 flores o tocando el corazón ❤️.
- 100% responsiva para celulares y desktop.

## 🚀 Publicar en GitHub Pages

1. Crea un repo nuevo en GitHub llamado `flores-amarillas-2026` (o el nombre que quieras).

2. En tu terminal, dentro de esta carpeta:

```bash
git init
git add .
git commit -m "Para María Isabel 💛"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/flores-amarillas-2026.git
git push -u origin main
```

> Si ya creaste la página desde el botón "+", sustitúyela por la URL que te muestra GitHub arriba a la derecha.

3. En GitHub: **Settings** → **Pages** → *Source*: **Deploy from a branch** → branch `main`, carpeta `/` → **Save**.

4. Espera ~1-2 minutos. Listo:

```
https://TU-USUARIO.github.io/flores-amarillas-2026
```

Comparte ese link con María Isabel 💛

## 📱 Verlo en el celular

Abre el link en el navegador del celular y dale tap. Con audífonos se escuchan mejor las campanitas.

## 💡 Tips

- El mensaje oculto y el remitente están en `index.html` (busca `card-msg` y `sign`) por si quieres cambiarlos.
- Si cambias el nombre del repo, también actualiza el `og:image` solo si el link debe apuntar a `og.png` (no hace falta: GitHub Pages sirve `/og.png` desde la raíz).
